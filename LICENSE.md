## About This Project

This repository contains a Python conversion and reimplementation of the
classic Maya **Rivet** MEL workflow originally created by Michael Bazhutkin /
studio Klassika in 2000–2001.

The original work is credited in the source code and below for historical
attribution.

**Python conversion, reimplementation, and additional development:  
AJOY**

## AJOY Python Version

The Python version in this repository was independently converted and
developed by **AJOY** for use with modern Maya Python workflows.

AJOY's implementation includes:

- Conversion from MEL to Python
- Maya Python integration using `maya.cmds`
- Corrected world-space mesh connection using `.worldMesh[0]`
- PySide2 / PySide6 support
- Custom warning dialog for invalid selections
- Updated implementation for modern Maya environments

The Python version is maintained and distributed by **AJOY**.
